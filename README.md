# Party Pals

A 4-player couch party game with 50 mini-games, made in Godot 4.4.

- **Play the browser prototype:** https://nathanmuba.github.io/party-pals/
- **Download the game (Windows / macOS / Linux):** see [Releases](https://github.com/nathanmuba/party-pals/releases/latest)

## Repository layout

| Path | What it is |
|---|---|
| `index.html` | Browser prototype (served by GitHub Pages) |
| `godot/` | Godot 4.4 project — open `godot/project.godot` in Godot. See [godot/README.md](godot/README.md) |

Built games are attached to each [release](https://github.com/nathanmuba/party-pals/releases) rather than committed, to keep the repo small.
